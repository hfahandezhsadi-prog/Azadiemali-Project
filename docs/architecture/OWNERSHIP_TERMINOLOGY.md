# Ownership Terminology

Status: Approved — terminology.
Owner: Product Owner

`TENANT_BUSINESS_OWNER` represents business ownership of Azadiemali, while `PLATFORM_OWNER` represents ownership of the software platform. The holders of these roles are recorded in operational data and contracts; the architecture is not tied to a person's name.

The legal controller of personal-data processing is determined by actual purposes and means, not by these application titles. See the [German data-protection baseline](../security/DATA_PROTECTION_AND_PRIVACY.md).
